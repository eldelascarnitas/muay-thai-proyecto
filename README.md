# muay-thai-proyecto
Página web informativa sobre la historia, las técnicas y los principios del Muay Thai.
Muay Thai: El arte de las ocho extremidades

Descripción

Este proyecto consiste en una página web informativa dedicada al Muay Thai, un arte marcial originario de Tailandia que utiliza puños, codos, rodillas y piernas. El propósito es presentar sus características principales, su historia y su importancia como disciplina deportiva y cultural.

Objetivo

Dar a conocer los fundamentos del Muay Thai, sus principales técnicas y los beneficios que puede aportar a quienes lo practican de manera responsable.

Contenido

Historia y origen del Muay Thai.

Técnicas fundamentales.

Beneficios físicos y mentales.

Disciplina, respeto y autocontrol.

Importancia del entrenamiento seguro.
